# Data rights and reuse

TWDisaster publishes normalized, non-personal factual records and provenance, not upstream PDFs, HTML archives, images, maps, logos, or other original payloads. Each source row names the original publisher, URL, retrieval time, and the official website reuse declaration used for this release. Reuse of a source-backed fact should attribute that publisher and URL. The dataset's original selection and arrangement may be reused under CC BY 4.0, subject to the upstream statements and the limits below.

The four source families included in version 0.1.0 are covered by the official website statements listed in [docs/sources.md](docs/sources.md). Those statements allow reuse with attribution and exclude certain third-party or specially marked material. This release includes no source prose, scans, images, identifiable personal data, or source document bytes. A source's `website_open_statement` status records the independent rights review for these normalized facts; it is not a claim that all material at the URL is licensed by TWDisaster.

This release applies the linked official website statements to a narrow set of non-personal facts and leaves sources without a qualified reuse basis outside the repository. Rights of excluded sources remain unresolved. A snapshot SHA-256 is integrity metadata, not a license grant.

Users should check the current publisher statement, any source-specific notice, and privacy implications before redistributing additional material. If a linked page or document has a special restriction, that restriction takes precedence for its content. See [provenance gaps](docs/provenance.md) for unresolved source and identity questions.
